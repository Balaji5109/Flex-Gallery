# 🖼️ Flex Gallery

A simple and responsive image gallery project built using **HTML, CSS, and JavaScript**, focusing on CSS Flexbox for arranging images in a clean and flexible layout.

## ✨ Features

- 📸 Clean and attractive image gallery layout
- 📱 Responsive design for different screen sizes
- 🎨 CSS Flexbox for flexible image arrangement
- ⚡ Lightweight and easy to use
- 🧩 Simple project structure for beginners

## 🛠️ Technologies Used

- **HTML5** – Structure of the gallery
- **CSS3** – Styling, layouts, and Flexbox
- **JavaScript** – Interactive functionality

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Balaji5109/Flex-Gallery.git
```

### 2. Open the project

```bash
cd Flex-Gallery
```

### 3. Run the project

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
